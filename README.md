# Планировщик задач

Мой итоговый проект по Go. Это веб-сервер для ведения списка задач (todo-лист). Можно добавлять задачи, редактировать, удалять и отмечать выполненными. Есть поддержка повторяющихся задач и поиск.

## Что я сделал

- Сервер на Go, который общается с фронтендом через REST API.
- База данных SQLite – задачи хранятся в ней.
- Задачи могут повторяться по правилам: `d` (каждые N дней), `y` (ежегодно), `w` (по дням недели), `m` (по дням месяца).
- Можно искать задачи по дате или по слову в заголовке / комментарии.
- Подключил JWT-аутентификацию (она включается, если задать пароль через переменную окружения `TODO_PASSWORD`).
- Сделал Dockerfile – можно запускать в контейнере.

## Как запустить локально

1. Установите Go (1.22 или новее).
2. Перейдите в папку с проектом и выполните:
go mod tidy

3. Запустите сервер:
go run cmd/main.go

4. Откройте в браузере: `http://localhost:7540`

Если хотите задать пароль, сделайте перед запуском:
export TODO_PASSWORD=ваш_пароль


## Переменные окружения (на всякий случай)

Переменная      Для чего                                       По умолчанию

`TODO_PORT`     На каком порту запускать сервер                `7540`       
`TODO_DBFILE`   Куда сохранять базу данных                     `scheduler.db` 
`TODO_PASSWORD` Пароль для входа (если нужен)                  не задан (вход без пароля)

## Тесты

Тесты лежат в папке `tests`. Запустить их можно командой:
go test ./tests

Для запуска тестов сначала запустите сервер в отдельном терминале:
go run cmd/main.go
Затем в другом терминале выполните:
go test ./tests
 Если у вас включена аутентификация, в файле `tests/settings.go` нужно указать валидный JWT-токен (но обычно тесты я запускал без пароля).

## Докер

Я добавил `Dockerfile`, так что можно собрать образ и запустить контейнер:

Собрать:
docker build -t scheduler .

Запустить (без пароля):
docker run -p 7540:7540 scheduler

С паролем:
docker run -p 7540:7540 -e TODO_PASSWORD=123456 scheduler


База данных будет создаваться внутри контейнера (файл `/app/scheduler.db`). 
Если хотите, что бы данные сохранялись после перезапуска, добавьте том:
docker run -p 7540:7540 -v /путь_на_хосте:/app scheduler


## Структура папок

- `cmd/` – главный файл `main.go`
- `pkg/` – основная логика (обработчики, база данных, сервер)
- `web/` – фронтенд
- `tests/` – тесты

## Что ещё

Все API отдают JSON. Если ошибка – в ответе будет поле `error`.  
Аутентификация проверяется через куку `token` (кроме `/api/signin`).
